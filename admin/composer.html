-- auto-drafted from query planner; runs in Databricks SQL WITH kw_spend AS ( SELECT sku, keyword, week_start, SUM(spend) AS spend FROM client_catalog.amazon.search_term_spend WHERE client_id = {{client_id}} AND retailer_id = 4 AND week_start BETWEEN {{prev_start}} AND {{curr_end}} GROUP BY 1,2,3 ), rank_wow AS ( SELECT sku, keyword, MAX(IF(week_start = {{prev_start}}, org_rank)) AS prev_rank, MAX(IF(week_start = {{curr_start}}, org_rank)) AS curr_rank FROM client_catalog.amazon.keyword_rank WHERE client_id = {{client_id}} GROUP BY 1,2 ) SELECT r.sku, r.keyword, k.spend, (r.curr_rank - r.prev_rank) AS rank_delta, r.prev_rank, r.curr_rank FROM rank_wow r JOIN kw_spend k ON k.sku = r.sku AND k.keyword = r.keyword WHERE k.spend > 1000 AND (r.curr_rank - r.prev_rank) >= 5 ORDER BY rank_delta DESC LIMIT 200;

Step 2c · Constraint rules

3 rules drafted. You can edit or add more.

DATA Week alignment

Use Sunday–Saturday weeks. Compare last complete week vs prior complete week.

ANALYSIS Threshold

A rank drop is meaningful only when prior_rank ≤ 30 AND drop ≥ 5 positions. Filter out from rank 50+.

PRESENTATION Output format

Group by SKU. Show top 5 affected keywords per SKU with rank_delta, spend, prev_rank, curr_rank. Render rank delta as "+N / -N" (negative = improved).
